# 02 · 刷机与回滚（Xiaomi Mi 5s Plus / natrium）

> ⚠️ 三条铁律
> 1. **只刷 `boot` 分区**，永远不要碰 `abl`/`xbl`/`tz`/`modem` 分区（那些刷错才是真砖）。
> 2. 先 `fastboot boot`（临时启动，不写 flash），确认能起来再 `fastboot flash boot`。
> 3. 回滚镜像就在本工程里：`bootimg/lineage-boot.img`，sha256 已记录，随时可以刷回去。

## 0. 前置

- 手机已解锁 bootloader（你在跑 LineageOS，所以必然是解锁状态）。
- 电脑装 Android platform-tools，`fastboot --version` 有输出。
- USB 线连接，手机进 **fastboot 模式**：关机后按住 `音量减 + 电源`，出现米兔/FASTBOOT 字样。
  验证：
  ```powershell
  fastboot devices            # 应显示 <序列号>  fastboot
  fastboot getvar product     # 应显示 product: natrium
  fastboot getvar unlocked    # 应显示 unlocked: yes
  ```

## 1. 零风险试启动（强烈建议先做这个）

```powershell
fastboot boot  boot-6.18.55-natrium-debug.img
```

- 这只是把镜像**下载到内存里启动一次**，不写入任何分区；拔线重启即回到原来的 LineageOS。
- 成功：屏幕出现内核 log（或 USB 串口出现 `natrium 6.18` 字样）。
- 若提示 `Boot image is not signed` / `Failed to boot`：说明这台 ABL 不允许临时启动，走第 3 步刷写。

## 2. 观测启动结果

| 通道 | 方法 | 需要什么 |
|---|---|---|
| 屏幕 | `fbcon`：内核 log 直接刷在 JDI 面板上，`natrium.config` 已开 `FRAMEBUFFER_CONSOLE` | 无 |
| USB 串口 | 手机插电脑后出现 ACM 串口，`screen /dev/ttyACM0 115200`（Linux）/ 设备管理器里的 COM 口（Windows 需装 USB 串口驱动） | initramfs 已自动配置 gadget |
| 真实 UART | 拆机接 GPIO4/5（MSM_UART），`console=ttyMSM0,115200n8` | 焊接，不推荐 |

串口里先看这几行：
```
Booting Linux on physical CPU ...
Linux version 6.18.55-natrium ...
msm 900000.mdss: [drm] ...
panel-jdi-fhd-r63452 ...
rmi4_i2c 6-0020: ...
ufshcd-qcom ...
```
只要能看到 `drm`/`panel`/`rmi4` 三行，显示与触摸链路就通了。

## 3. 正式刷写

```powershell
# 3.1 先备份当前 boot（本工程已含，但你自己再备一份更稳）
fastboot getvar current-slot           # natrium 非 A/B，无输出属正常
fastboot flash boot bootimg\lineage-boot.img   # 可选：把原厂再刷一遍确保基线
# 3.2 刷入 6.18
fastboot flash boot boot-6.18.55-natrium-debug.img
fastboot reboot
```

## 4. 回滚（30 秒）

```powershell
fastboot devices
fastboot flash boot bootimg\lineage-boot.img      # 原厂 4.4.302
fastboot reboot
```

回滚镜像校验（应与下载时一致）：
```powershell
Get-FileHash bootimg\lineage-boot.img -Algorithm SHA256
# 1c6fc3896e8949dc9ca78eaf1fe13ebafc3e164910fa1c32ef169952054b3e62
```

## 5. 如果连 fastboot 都进不去（自救）

1. 长按电源 15 秒强制断电，再按住 `音量减 + 电源` 进 fastboot。
2. 进不去 → 尝试 `音量加 + 电源` 进 recovery。
3. 都不行 → **EDL 9008 模式**（关机后同时按住 `音量加+音量减` 插线），用小米售后工具/授权账号恢复。
   只要没动 `abl/xbl`，硬件不会真砖。

## 6. 常见现象对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 完全黑屏、无 USB、10 秒后自动重启 | DTB 没被 ABL 选中（board-id/msm-id 不匹配）或内核 panic | `fastboot flash boot` 回滚；检查 `qcom,msm-id = <305 0x10000>`、`qcom,board-id = <47 0>` |
| 屏幕亮但停在第一屏且无 log | 缺 `fbcon`/`DRM_FBDEV_EMULATION` | 确认 `.config` 里两项为 `y`（构建脚本已自检） |
| 屏幕全黑但 USB 串口有 log | 背光没开 | initramfs 已自动把 `brightness` 拉满；否则手动 `echo 255 > /sys/class/backlight/*/brightness` |
| `Kernel panic - not syncing: VFS: Unable to mount root` | cmdline/rootfs 不对 | bring-up 镜像请用 `root=/dev/ram0 init=/init`（本工程默认） |
| 触屏无反应 | rmi4 没匹配到 I2C 地址 | `dmesg | grep -i rmi4`；确认 `CONFIG_RMI4_I2C=y`，DTS 里 `touchscreen@20` |
| WiFi 起不来 | 缺 `wlan/prima` 固件 | 把固件放到 `/lib/firmware/wlan/prima/`（pmOS 的 `firmware-xiaomi-natrium` 包里有） |
